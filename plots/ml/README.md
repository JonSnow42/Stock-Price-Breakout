# Machine Learning Evaluation Visualizations

This directory contains the six publication-quality evaluation figures generated by [`03_model_comparison_visualization.R`](../../03_model_comparison_visualization.R) evaluating all ten machine learning models on the held-out test dataset (19,600 observations; 2025–2026).

---

## 📈 Figure Inventory & Performance Analysis

### 1. `01_roc_curves_test.png` — Receiver Operating Characteristic (ROC) Curves
- **Description:** ROC curves (True Positive Rate vs. False Positive Rate) for all ten models on the held-out test set.
- **Formulas:**
  $$\text{TPR} = \frac{\text{TP}}{\text{TP} + \text{FN}} = \text{Recall}, \quad \text{FPR} = \frac{\text{FP}}{\text{FP} + \text{TN}}$$
- **Key Takeaways:**
  - **High Global Discrimination:** All ten classifiers exceed an ROC-AUC of 0.80, demonstrating strong capacity to distinguish potential breakout days from ordinary trading sessions.
  - **Top Models:** Neural Network (MLP) achieved the highest ROC-AUC (**0.8582**), followed closely by XGBoost (**0.8573**), Logistic Regression (**0.8554**), and Gradient Boosting (**0.8536**).
  - **Limitation of ROC in Imbalanced Data:** Because True Negatives ($18,655$) are overwhelming, the False Positive Rate denominator ($\text{FP} + \text{TN}$) remains large, making ROC curves appear overly optimistic.

---

### 2. `02_precision_recall_curves_test.png` — Precision-Recall Curves (Primary Benchmark)
- **Description:** Precision-Recall curves mapping precision against recall across all possible decision thresholds, with the uninformative random guessing baseline ($\text{PR-AUC} \approx 0.0215$) marked by the dashed horizontal line.
- **Formulas:**
  $$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}, \quad \text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$
- **Key Takeaways:**
  - **The True Differentiator:** While ROC curves are tightly grouped, PR curves show dramatic performance divergence.
  - **Champion Model:** **Gradient Boosting (GBM)** dominates the critical $10\%$ to $40\%$ recall corridor, securing a test PR-AUC of **0.1721**—an **$8.0\times$ lift** over the random guessing baseline ($0.0215$).
  - **Neural Network Strength at High Recall:** Neural Network (MLP) maintains the highest precision at extreme recall levels ($>40\%$), achieving a PR-AUC of **0.1645**.
  - **XGBoost:** Follows closely with a PR-AUC of **0.1630**.

---

### 3. `03_model_comparison_test.png` — Multi-Metric Comparative Bar Charts
- **Description:** Faceted bar chart comparing all ten algorithms across the three primary performance dimensions: ROC-AUC, PR-AUC, and F1-score on the held-out test set.
- **Key Takeaways:**
  - **F1 Champion:** Gradient Boosting achieves the highest F1-score (**0.2451**), striking the optimal trade-off between alert precision ($20.15\%$) and breakout coverage ($31.28\%$).
  - **XGBoost & Neural Network:** Follow closely with F1 scores of **0.2414** and **0.2394**, respectively.
  - **Linear Model Baseline:** Logistic Regression ($F_1 = 0.2327$) and LDA ($F_1 = 0.2301$) perform commendably, proving that the engineered features have substantial linear separability.

---

### 4. `04_tuning_improvement.png` — Hyperparameter Tuning Performance Delta
- **Description:** Grouped bar chart illustrating the validation-stage PR-AUC progression from default hyperparameter settings to tuned configurations.
- **Key Takeaways:**
  - **Decision Tree Gain:** PR-AUC advanced from $0.0978$ to $0.1059$ ($+8.3\%$) by tuning `cp = 0.001`, `maxdepth = 8`, and `minsplit = 100`.
  - **KNN Gain:** PR-AUC expanded from $0.1137$ to $0.1277$ ($+12.3\%$) by increasing neighborhood size $k$ to $81$, smoothing out local microstructure noise.
  - **Neural Network Gain:** PR-AUC surged from $0.1123$ to $0.1319$ ($+17.5\%$) by increasing weight decay regularization to $\lambda = 0.10$, preventing weight over-fitting.

---

### 5. `05_feature_importance.png` — Top 12 Predictive Features (GBM, RF, XGBoost)
- **Description:** Relative feature importance rankings (%) for tree-based ensemble models derived from Gini impurity reduction and gradient gain.
- **Key Takeaways:**
  - **`Dist_High_20` (Distance to 20-Day High):** Dominates all tree models ($43.13\%$ in GBM, $32.89\%$ in XGBoost). Stocks consolidating immediately beneath prior resistance provide the strongest signal of next-day breakout potential.
  - **`Log_Vol_Ratio` (Log Volume to 20-Day Baseline):** Second most important feature ($40.57\%$ in GBM, $25.03\%$ in XGBoost). Extraordinary volume confirms institutional accumulation.
  - **Combined Dominance:** `Dist_High_20` and `Log_Vol_Ratio` jointly account for **$83.70\%$** of total predictive importance in the winning Gradient Boosting model.

### 6. `06_confusion_matrix_best_model.png` — Champion Model Confusion Matrix Heatmap
- **Description:** Confusion matrix heatmap for Gradient Boosting (GBM) evaluated on the 19,600 held-out test instances at the validation-calibrated threshold $\tau^* = 0.4717$.
- **Empirical Cell Breakdown:**
  - **True Negatives (TN):** $18,655$ instances ($97.27\%$ specificity on non-breakout days).
  - **False Positives (FP):** $523$ instances (breakout alerts that failed to trigger next day).
  - **False Negatives (FN):** $290$ instances (breakouts missed by the model).
  - **True Positives (TP):** $132$ instances (confirmed breakouts successfully predicted 24 hours in advance).
  - **Operating Metrics:** $\text{Precision} = 132 / (132 + 523) = 20.15\%$; $\text{Recall} = 132 / (132 + 290) = 31.28\%$.
